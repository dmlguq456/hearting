# Field fundamentals

Sound fundamentals, your own way. For each of seven fields of work, this directory holds one short page of the fundamentals that nearly everyone in that field keeps. Each page is written so that a person in the field can read it and correct it. The Korean pair of each page is `<name>.ko.md`; the English page is the original.

## The fields

| Field | Makes |
|---|---|
| [`plan`](plan.md) | what to build, converged in discussion with the user and written down |
| [`design`](design.md) | the visible form a person chose |
| [`code`](code.md) | working software |
| [`lab`](lab.md) | measured results under stated conditions, and their interpretation |
| [`research`](research.md) | what was found out from outside sources, with its sources |
| [`docs`](docs.md) | writing meant to be read (papers, reports, talks) |
| [`admin`](admin.md) | documents submitted in a prescribed form |

The names are in English only. There is no separate name per language.

## What these pages are, and are not

They are a short list of fundamentals per field, each with a one-line gloss and the sources it comes from. Only what two independent searches confirmed, at least one from the original text, is listed.

They are not a method. They do not set the order of the work, the tools, how deep to go, or how large a piece of work must be before a document is written. Those differ from person to person, and each page has a "Not decided here" section that says so. A line that binds a way of doing something does not belong on these pages.

A common unit that keys part of its reference by field (`### 참고 — <field>`) gets the `## Fundamentals` lines of its route's field carried with its worker text, without the glosses and sources; nothing else reads these pages.

## `other`

`other` is the name the opening session writes for work that fits none of the seven fields. It is not the default when no field is written, and it has no page of fundamentals.

## To change a page

If a page is wrong or missing something, tell us in an issue or a pull request on the Hearting repository. Anyone who works in the field is welcome to. There is no form to fill in and no separate channel.

Keep each fundamental on one line in the form `- head sentence — gloss [source]`. Only the head sentence is carried with the worker text; a line wrapped by indenting is joined to the item above it.
