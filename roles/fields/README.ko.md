# 갈래의 기본

기본은 단단히, 방식은 자유롭게. 일곱 갈래마다, 그 분야에서 거의 누구나 지키는 기본을 한 쪽 글로 이 폴더에 둔다. 그 분야 사람이 읽고 고칠 수 있게 쓴 글이다. 한국어 짝은 `<이름>.ko.md`이고, 영어 글이 정본이다.

## 갈래

| 갈래 | 만드는 것 |
|---|---|
| [`plan`](plan.ko.md) | 사용자와 논의해 수렴한 무엇을 만들지, 그리고 그것을 적은 글 |
| [`design`](design.ko.md) | 사람이 고른 보이는 꼴 |
| [`code`](code.ko.md) | 돌아가는 소프트웨어 |
| [`lab`](lab.ko.md) | 조건이 붙은 측정 결과와 그 해석 |
| [`research`](research.ko.md) | 바깥에서 알아낸 것과 그 출처 |
| [`docs`](docs.ko.md) | 읽힐 글(논문, 보고서, 발표) |
| [`admin`](admin.ko.md) | 정해진 양식대로 내는 서류 |

갈래 이름은 영어 한 벌이다. 언어별 이름은 따로 두지 않는다.

## 이 글이 무엇이고 무엇이 아닌가

갈래마다 기본 몇 가지를 한 줄 풀이와 출처와 함께 적은 글이다. 두 조사가 따로 확인했고 한쪽이 원문을 읽은 것만 넣었다.

방법이 아니다. 일의 차례, 도구, 깊이, 문서를 쓸 일의 크기는 정하지 않는다. 사람마다 다른 자리라서, 쪽마다 "정하지 않는 것"에 적어 두었다. 방법을 묶는 줄은 이 글에 들이지 않는다.

참고를 갈래별로 나눠 둔 공통 유닛(`### 참고 — <갈래>`)에는 route 갈래의 `## Fundamentals` 줄이 풀이와 출처 없이 작업자 글에 함께 실린다. 그 밖에 이 글을 읽는 것은 없다.

## `other`

`other`는 일곱 갈래 어디에도 맞지 않는 일에 여는 쪽이 적는 이름이다. 갈래를 적지 않았을 때의 기본값이 아니며, `other`의 기본 글은 없다.
