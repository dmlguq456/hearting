# admin

서류·행정(admin)은 남이 정한 양식에 맞춰 내는 서류, 곧 공문, 과제 보고서, 특허 의견서, 신청서, 인수인계 문서를 만드는 일이다.

## 기본 (빼지 않는다)

- 받는 쪽이 정한 서식과 기한을 따른다. — 서식, 기한, 요건은 받는 쪽(법령, 기관, 통지서)이 정하고, 쓰는 사람이 임의로 바꾸지 못한다. [1–6]
- 권한 있는 사람이 결재한다. — 권한 있는 사람의 결재나 인증이 있어야 문서가 선다. [1–6]
- 흔적을 남긴다. — 등록번호, 서명과 날짜, 편철, 보존, 판 관리를 남긴다. [1–6]
- 알기 쉽게 쓴다. — 받는 사람이 알 수 있는 용어와 문장으로 쓴다. [1–6]

## 정하지 않는 것

사람과 기관마다 다른 자리라서 이 글이 열어 둔다: 결재를 어디까지 내릴지(기관의 규칙이 정한다), 무엇을 생략할 수 있고 그 사유를 어떻게 적을지, 어떤 제출 시스템을 쓸지, 인수인계를 어떻게 할지, 기한보다 얼마나 일찍 낼지.

## 다른 갈래와의 경계

- 문서의 본문을 쓰는 일은 `docs`다. 서식, 기한, 결재, 제출, 기록 보관은 서류·행정이다.
- 특허 의견서는 논거를 쓰는 글이지만 기한과 보정 범위가 법으로 묶여 있어 서류·행정에 더 가깝다.
