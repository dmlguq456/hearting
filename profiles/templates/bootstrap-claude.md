## Claude masked-profile attach layer

This config home exposes only the selected Skills, agents, guard settings, and
specialization fragment. The dispatch prompt supplies the worker's instructions:
the portable worker kernel and one worker-type fragment, or for a unit route a
short first instruction with the unit's text and the kernel's safety lines. Do
not reread the four main core documents or a full adapter bootstrap unless the
assignment names a specific section as required input.

`CLAUDE_CONFIG_DIR` attaches this partial projection. Runtime-owned project or
user `CLAUDE.md` inheritance may still occur and is not represented as physical
masking by this profile.
